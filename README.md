# libGDX Agent Gameplay

`libgdx-agent-gameplay` is a deterministic ECS-lite gameplay architecture for agent-driven
libGDX projects. It constrains entity composition, fixed-tick systems, commands, lifecycle,
runtime evidence, Box2D ownership, and rendering into one inspectable model.

The repository currently targets JDK 25 and libGDX 1.14.2. Its four library artifacts are
`gameplay-core`, `gameplay-libgdx`, `gameplay-runtime`, and `gameplay-box2d`; the
`gameplay-fixture` application is the non-published qualification game.

No Maven Central release exists yet. Publication requires separate authorization.
