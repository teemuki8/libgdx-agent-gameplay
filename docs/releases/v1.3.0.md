# libgdx-agent-gameplay 1.3.0

This additive release improves application-owned presentation and runtime evidence:

- RenderView records physical viewport/framebuffer geometry. RenderViewCoordinates maps
  top-left physical input into the world and excludes letterbox bars with half-open edges.
- PresentationFrame optionally interpolates consecutive snapshots, including shortest-path
  rotation. Rendering and visual evidence share presentation poses; collision evidence and
  gameplay authority remain current-tick facts. Reset and teleport continuity is caller-owned.
- EventCodecRegistry provides bounded exact-class event codecs with canonical runtime payloads.
- GameplayRuntimeBridge offers capacity preflight and opt-in completeness rejection, including
  nested truncation, diagnostics and incomplete decisions.

The application still owns fixed ticks, threads, physics, rendering and resource disposal.
Presentation never changes simulation digests, commands or runtime authority. No new input path,
UI construction mechanism or world serializer is introduced.

Align gameplay-core, gameplay-libgdx, gameplay-runtime and gameplay-box2d on 1.3.0 when available.
The fixture is not published. JDK 25 and the official Box2D 3 backend remain required.
The released API comparison baseline is 1.2.0; strict locks and checksums cover that baseline.

Publication requires validated exact coordinates and a separate Central publish operation.
This candidate note does not itself establish publication or non-desktop qualification.
